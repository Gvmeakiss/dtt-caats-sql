# dtt-caats-sql · 通用 CAATS / 勾稽 SQL 模板

> 个人学习用、已完全脱敏的通用计算机辅助审计（CAATS）SQL 模板合集。
> 所有代码使用合成的 `T_` / `dwd_` 表与字段，不含任何客户、平台、地址、账户等真实信息。
> 非任何前雇主资产，仅用于演示审计分析技法。

## 目录
- `HM/`  销售订单 ↔ 收入勾稽、产品物料追索（BOM）
- `JSM/` 销售出库单审计（交付 / 退货 / 刷单 / 分销商 / 渠道集中度）
- `BHSZ/` 证券佣金重算
- `BHYH/` 应付利息预提（JAT）
- `CSDN/` 支付流水合并对账、会员权责（递延收益）确认

## 包含的审计技法
- 多源数据勾稽（订单 / 收入 / 退货 / 账单）
- 外币折算本位币、退货冲红、关联方剔除
- 数据质量空值 / 重复值检查
- 金额 / 客户 / 地址 / 渠道集中度分析
- 业务真实性（运输天数异常、刷单、囤货）识别
- 重算比对（佣金、利息、递延收益）
